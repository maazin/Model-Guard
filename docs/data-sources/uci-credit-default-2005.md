## Intended use in ModelGuard

Training and validating the `pd-credit-v2.x` model versions and exercising the full governance lifecycle on real,
licensed data. Portfolio simulation only; not a lending decision engine.

## Schema and adapter

30,000 Taiwanese credit-card holders, 23 explanatory variables (April–September 2005) and a binary target
`default payment next month`. `UciCreditDefaultAdapter` (`packages/ml/modelguard_ml/adapters.py`) engineers the
features below; the full data dictionary is rendered into every version's data-lineage document.

| Normalised feature | Derived from |
| --- | --- |
| `credit_limit` | `LIMIT_BAL` |
| `utilization_recent`, `utilization_mean` | `BILL_AMT1 / LIMIT_BAL`, `mean(BILL_AMT1..6) / LIMIT_BAL` |
| `pay_status_recent`, `pay_status_max`, `months_delinquent` | `PAY_0`, `max(PAY_0..PAY_6)`, `count(PAY_x > 0)` |
| `bill_amt_mean`, `pay_amt_mean`, `pay_to_bill_ratio` | row means and `sum(PAY_AMT) / sum(max(BILL_AMT, 0))` |
| `sex` (fairness diagnostics only) | `SEX` (1 = male, 2 = female) |

`AGE`, `EDUCATION` and `MARRIAGE` are dropped; `SEX` is never a feature (ADR-0004).

## Monitoring batches

The dataset is a single cross-section, so `scripts/generate_uci_batches.py` derives three dated batches
(4,000-row samples in the raw column layout) with documented, deterministic perturbations: stable; bills +10% /
payments −15%; limits −20% / payments −40% / +1 delinquent month for 40% of rows. Labels are carried over unchanged.
They are stored under `data/sources/uci-credit-default-2005/monitoring/` (git-ignored) and re-generated by the seed.

## Limitations

- No origination or observation date, so the split is stratified (ADR-0003): no out-of-time performance estimate.
- Credit-card revolving balances in NT$, not instalment loans; income, term and interest rate do not exist.
- Coding of `EDUCATION` levels 0, 5 and 6 is undocumented in the source.
- Monitoring batches are generated stress scenarios, not later real cohorts.
- 2005 Taiwan data; results say nothing about any other market or period.

# ADR-0001: Dataset and license

**Status:** Accepted for the MVP. **The choice of a real public dataset is deliberately deferred to the developer**, who must confirm its license before any import.

## Context

The PRD requires "one properly licensed, publicly accessible loan-performance or consumer-credit dataset" and forbids inventing license facts or downloading data without a human confirming the license.

## Decision

1. The repository ships with, and every test and the demo run on, an **in-repo synthetic fixture** (`data/fixtures/synthetic_loans.csv`, generated by `scripts/generate_fixtures.py` from `modelguard_ml.synthetic`). It is MIT-licensed with the rest of the repo, contains no real borrowers, and is registered as data source `synthetic-loans-v1` with an explicit limitations statement.
2. Real datasets are loaded through the pluggable adapter in `packages/ml/modelguard_ml/adapters.py`: a column-mapping adapter normalises any source into the ModelGuard schema. The API only imports files that already sit under `data/` — nothing is fetched automatically.
3. Before a real dataset is imported, the developer must (a) read its license page, (b) write `docs/data-sources/<source_id>.md` (the `POST /api/v1/data-sources` endpoint creates the skeleton with the license URL, allowed use and retrieval date), and (c) confirm the license by registering the source as a named demo user, which is recorded in the audit log.

## Candidates the developer may evaluate (not verified here)

| Candidate | Why it fits | What must be checked by a human |
| --- | --- | --- |
| UCI "Default of Credit Card Clients" | Small, tabular, binary default target | License on the UCI listing (commonly CC BY 4.0) and citation requirement; no time field, so ADR-0003's temporal split would fall back to stratified |
| UCI "Statlog (German Credit Data)" | Classic credit dataset | Same as above; 1,000 rows only |
| Freddie Mac / Fannie Mae single-family loan-level data | Real loan performance with monthly time series | Requires registration and acceptance of the provider's terms of use; check redistribution and derived-work restrictions before committing any subset |

None of these is used or claimed in this repository; the executive memo and deck report only synthetic-fixture results.

## Consequences

- Results are illustrative and do not transfer to any real portfolio; this is stated in the README, model card, and executive summary.
- The schema, quality checks and monitoring pipeline are exercised end to end offline.
